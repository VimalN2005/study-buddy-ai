# 🎓 StudyBuddy AI - Build for a Friend

> Built for the **Hacktoberfest 2026 Open-Source AI Weekend Challenge: Build for a Friend**.

StudyBuddy AI solves a genuine college problem: helping friends transform dense, intimidating lecture notes and complex concepts into structured study kits (Executive Summaries, High-Yield Active-Recall Quizzes, and Flash Cheat-Sheets) powered by open-weight AI models (e.g., Meta Llama-3).

---

## 🌟 Features
- **⚡ Executive Bullet Summary:** Breaks down walls of text into essential conceptual points.
- **🧠 Interactive Active-Recall Quiz:** Generates tailored MCQs with instant scoring, feedback, and conceptual explanations.
- **📌 Flash Cheat-Sheet:** Extracts critical terminology, equations, and definitions for quick pre-exam revision.
- **🔓 Open-Weight AI Core:** Designed to run with open-source models (Meta Llama-3 via Groq or Hugging Face Inference API) with an included zero-setup offline demo mode.

---

## 🚀 Quickstart

### 1. Clone the repository
```bash
git clone https://github.com/VimalN2005/study-buddy-ai.git
cd study-buddy-ai
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.
